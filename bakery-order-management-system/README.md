# Bakery Order Management System

A simple order management system for a small bakery/café, developed as part of the Software Systems Development course at the University of Minho.

The application manages the full lifecycle of customer orders, from registration at the counter to preparation and delivery, while also providing basic stock control and sales information.

## Features

- Register customer orders
- Add multiple products to an order
- Support simple product customizations
- Automatically calculate the total order price
- Track order status:
  - Registered
  - In Preparation
  - Ready
  - Delivered
- Display products waiting for preparation
- Estimate pending preparation time
- Track ingredient stock
- Notify when ingredients reach minimum stock levels
- View basic sales information
- Identify the most sold products


## Architecture

The project follows an object-oriented, multi-layer architecture.

The system was designed using UML before implementation, including:

- Domain Model
- Use Case Diagram
- Class Diagrams
- Sequence Diagrams
- Package Diagram
