# Locky Share Web

Locky Share Web is an ASP.NET Core web application developed as an evolution of a previous console-based locker management system, designed to manage physical locker cabinets in a multi-user environment accessible through a browser. The system allows users to deposit packages in available lockers and collect them using unique access codes, while supporting different roles such as clients, operators and administrators with specific permissions for locker management, status consultation, overrides and operator activation. Data persistence is handled with SQL Server and Entity Framework Core, including database migrations, and the application also supports importing locker configurations from JSON files. The project includes unit tests to validate key business logic such as unique code generation, JSON parsing and other core system behaviours.
