# Projects developed so far

Bakery Order Management System: a simple order management system for a small bakery/café, developed as part of the Software Systems Development course at the University of Minho.

Process Management System: project developed in C in the context of an Operating Systems course. The goal is to simulate a command execution environment using multiple runner programs coordinated by a controller, with inter-process communication, named pipes, command scheduling, concurrent execution, and persistent execution records.

Locky-Share: an ASP.NET Core web application designed to manage physical locker cabinets in a multi-user environment accessible through a browser.
